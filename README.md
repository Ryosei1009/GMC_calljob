# 🔔 gmc_calljob

**警察署や病院の受付で E キーを押すと、勤務中の警察・救急隊を呼び出せる、FiveM 用のリソース**

</div>

GTA5 のロールプレイサーバー「GMC RP」向けに作った FiveM のリソースです。
警察署のロビーや病院に来たプレイヤーが、その場で E キーを押すだけで、勤務中の警察官や救急隊員に「お客さんが待っている」と知らせられます。

GMC RP は約 2 年間、日本トップの人気を誇ったサーバーです。
このリソースのほかに、ゲーム内スマホのアプリ「Style N&B」や、「新商品申請フォーム」などの Web アプリも作りました。

## 使い方

| 場所 | 呼び出す相手 | 届く通知の例 |
| --- | --- | --- |
| 警察署（本署ロビー） | 警察 | 「本署ロビーで〇〇様がお待ちです。」 |
| 病院 | 救急隊 | 「病院で〇〇様がお待ちです。」 |

1. 呼び出し場所に近づくと、画面に「[E] 警察を呼び出す」のような案内が出ます
2. E キーを押すと、該当するジョブのプレイヤーにディスパッチ（出動要請）が届きます
3. 呼び出した人にも「警察を呼び出しました。」と通知が出ます

同じ場所からの呼び出しは 5 分に 1 回までで、待ち時間中は「あと〇分〇秒で呼び出せます」と表示されます。

## 工夫したところ

### 設定ファイルだけで呼び出し場所を増やせる

呼び出し場所は `config.lua` にまとめてあり、座標、反応する距離、待ち時間、表示する文言、通知を届けるジョブを場所ごとに設定できます。
コードを書き換えなくても、設定を 1 つ足すだけで新しい呼び出し場所を追加できます。

### 呼び出しの連打を防ぐ

場所ごとに待ち時間（クールダウン）を設けて、同じ場所から何度も呼び出せないようにしました。
残り時間を「〇分〇秒」の形で表示するので、いつまた呼び出せるかがすぐに分かります。

### 既存の仕組みと自然につながる

- 呼び出しは ps-dispatch の通知として届くので、警察や救急隊はふだんの出動要請と同じ画面で確認できます
- 通知には呼び出した人の名前と位置が入るので、誰がどこで待っているかがすぐに分かります
- 案内の表示には okokTextUI、通知には okokNotify を使い、サーバーのほかの機能と見た目をそろえています

### 負荷を抑えた位置の確認

呼び出し場所の近くにいるときだけ毎フレームキー入力を確認し、離れているときは 0.5 秒おきの確認にして、処理の負荷を抑えています。

## 技術スタック

| | |
| --- | --- |
| **Game** | FiveM（Lua）, QBCore |
| **連携** | ps-dispatch（出動要請）, okokTextUI（案内表示）, okokNotify（通知） |

```
プレイヤー（受付で E キー）
   │
   ▼
client.lua ──▶ server.lua ──▶ ps-dispatch ──▶ 勤務中の警察・救急隊
   │              │
   │              └─▶ okokNotify：呼び出した人に通知
   └─▶ okokTextUI：案内と待ち時間の表示
```

## ディレクトリ構成

```
.
├── fxmanifest.lua   # FiveM リソースの設定
├── config.lua       # 呼び出し場所、待ち時間、文言、通知先のジョブ
├── client.lua       # 場所の判定、案内の表示、E キーの受付
└── server.lua       # ディスパッチの送信と通知
```
